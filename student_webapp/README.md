# 客户分群实验对照看板

直接双击 index.html；请保留整个 student_webapp 文件夹，不需要服务器、联网或安装依赖。

默认两特征、seed42。选择模型及随机种子后，四指标、散点图、画像、服务假设和当前下载配置同步更新；恢复默认同时回到年龄对照面板。支持六种实际计算配置，不在网页内训练。

CSV保留原始七列（balance为元），另含原始簇号、展示簇号、特征和参数。散点图的income/balance均为万元。颜色仅在同方案内对齐至seed42，跨方案同色不代表成员相同。不同seed可能真实分组相同，不能仅凭点位未改变判断切换失效。

数据来自教师教学模拟包。业务命名待本人核对，建议仅为待验证的服务假设。页面功能的本人验收见项目 reports/tool_acceptance.md。
