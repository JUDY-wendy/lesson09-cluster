# 零售银行客户分群分析报告

## 一、分析方法

- 数据：`data/mall_customers_yuan.csv`，共 300 位客户、7 个原始字段。
- 聚类特征：仅使用 `income`（年收入，万元）与 `balance`（账户平均余额，元）两列；`customer_id` 仅作编号，不参与建模。
- 预处理：`balance` 以元计、`income` 以万元计，量纲相差约四个数量级，聚类前用 `StandardScaler` 对两列做标准化（z 分数），使两特征等权参与欧氏距离计算。
- 算法：k-均值聚类（KMeans），簇数 k=3，随机种子 `random_state=42`，`n_init=10`。
- 流程：先做数据初检与初始散点图（`outputs/01_raw_scatter.png`），再聚类并绘制同一模型在原始坐标与标准化坐标下的对照图（`outputs/04_compare_scale.png`）。
- 数据与报告性质：使用教学模拟数据；本报告为阶段草稿，正式业务建议与综合结论待后续完整实验补齐。
