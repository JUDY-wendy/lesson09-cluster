## 一、设计

### 仅 random_state 改变，其余全部固定

| 项 | 值 |
|---|---|
| 数据 | mall_customers_yuan.csv，300 客户，按 customer_id 对齐 |
| 特征 | income, balance, age（按此固定顺序） |
| StandardScaler | with_mean=True, with_std=True, copy=True（对上述三列一起做一次 fit_transform） |
| KMeans | n_clusters=3, init=k-means++, n_init=10, max_iter=300, tol=1e-4, algorithm=lloyd, copy_x=True, verbose=0 |
| random_state | **0, 42, 2026**（三次独立 fit_predict） |

参数从 `feature_compare/metrics.json` 读取并逐项核对：固定参数（n_clusters / init / n_init / max_iter / tol / algorithm / copy_x / verbose）必须与文件中的 KMeans 参数完全一致；StandardScaler 参数必须完全一致；特征顺序必须等于 `["income", "balance", "age"]`；yuan SHA256 必须等于文件记录且等于已知基线。

### seed42 交叉核验（脚本内 fail 分支）

seed42 的拟合结果与 `feature_compare/feature_labels.csv` 的 `cluster_3f` 按 customer_id 比对：
- ARI 必须 >= 1 - 1e-6；
- 匈牙利最大重叠匹配 matched 必须 = 300；
- changed 必须 = 0；
- 不要求原始簇编号完全相同（ARI 本身不受编号置换影响，匹配消除编号差异后比较）；
- **任一条件不满足立即 fail 退出，不调参凑一致**。

### 展示映射方向（显式，不混淆）

- 每个 seed 拟合完后，对 seed 簇编号数组和 seed42 簇编号数组调用 `max_overlap(seed_labels[sd], seed_labels[42])`，返回 `seed_sd → seed_42` 的匈牙利映射；
- 此映射命名为 `display_maps[sd]`，**方向明确：行=当前 seed 簇，列=seed42 簇**；
- 所有展示用途（labels 展示列、画像 display_cluster 列、绘图颜色）都用 `display_maps[sd][原始簇]` 把当前 seed 的簇编号映射到 seed42 簇编号作为颜色索引；
- metrics.json 元信息中写明 `"display_mapping_direction": "行=当前seed簇编号，列=seed42簇编号；mapping 为 current_seed → seed42"`；
- **不假设自反**——三特征实验里映射恰好自反，但稳定性实验里三个 seed 的两两映射不一定自反。

### 三对 pairwise 方向也明确

| pair | 匈牙利 rows | 匈牙利 cols | mapping 名 |
|---|---|---|---|
| 0 vs 42 | seed0 簇 | seed42 簇 | mapping_0_to_42 |
| 0 vs 2026 | seed0 簇 | seed2026 簇 | mapping_0_to_2026 |
| 42 vs 2026 | seed42 簇 | seed2026 簇 | mapping_42_to_2026 |

行总是第一个 seed，列总是第二个 seed，不反转。`pairwise_comparisons.csv` 里用 `pair, seed_a, seed_b, mapping_a_to_b` 明确写方向；`contingency_tables.csv` 里用 `row_seed_cluster, col_seed_cluster` 明确行列归属。

### 单一完整 DataFrame 贯穿

`prepare_data()` 一次性读完 yuan + fc_labels 后生成 `df`，带：customer_id / age / income / balance / balance_wan / product_count / gender / city / seed42_cluster_from_fc 全部字段。后续 fit_all、pairwise_and_display、export、plot 全部传这一个 `df`（加 `X_sc` 标准化矩阵），不创建局部临时列后丢弃。避免 02_feature_compare.py 里 balance_wan / cluster_2f / cluster_3f 局部作用域错误。

### 不预设结果

三个 seed 各实际 fit_predict，不预设 ARI 高、变化少或稳定性好。若三对 pairwise ARI 都接近 1、匹配变化接近 0，说明对初始化不敏感；若差异大，如实报告。
